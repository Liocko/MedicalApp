"# Medical App - MVP

Medical App - это простое приложение для управления медицинскими записями и пациентами, созданное с соблюдением принципов 12 Factor App.

## Особенности

- Управление пациентами
- Управление врачами
- Записи на прием
- Назначения
- Диагнозы
- Отчеты

## Принципы 12 Factor App

- Конфигурация в переменных окружения
- Отделение кода от конфигурации
- Один код на один репозиторий
- Зависимости явно объявлены
- Развертывание портативно
- Логирование как поток событий
- Администрирование через процессы

## Установка

1. Склонируйте репозиторий
2. Создайте виртуальное окружение
3. Установите зависимости: `pip install -r requirements.txt`
4. Создайте файл `.env` на основе `.env.example`
5. Выполните миграции: `python manage.py migrate`
6. Запустите сервер: `python manage.py runserver`

## Структура проекта

- `patients/` - модули управления пациентами
- `records/` - модули медицинских записей
- `core/` - основные компоненты системы
- `config/` - конфигурационные файлы

## Переменные окружения

См. файл `.env.example` для примера.
